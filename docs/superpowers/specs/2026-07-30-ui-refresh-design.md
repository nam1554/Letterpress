# 홈 · 작업 상세 UI/UX 개선 설계 (2026-07-30)

사용자 보고: "전체적으로 스타일이 뭔가 어색해".

원인 조사 결과 취향 문제가 아니라 **측정 가능한 결함 4종**이었다. 아이덴티티
(크림 배경 · 테라코타 액센트 · 세리프 헤딩)는 유지하고, 토큰과 구조를 다시 짠다.

## 1. 진단 (실측)

실행 중인 앱에서 `getComputedStyle`로 확인한 값들이다.

### (a) 웜 배경에 쿨 뉴트럴 — 라이트 모드 전역

`app/theme.ts`가 `clay`와 `dark` 팔레트만 정의하고 **`gray`를 덮지 않아서**,
라이트 스킴의 모든 뉴트럴이 Mantine 기본 블루그레이로 남았다.

| 토큰 | 실측값 | 성격 |
| --- | --- | --- |
| `--mantine-color-dimmed` | `#868e96` | 쿨 (대비 3.9 — AA 미달) |
| `--mantine-color-default-border` | `#ced4da` | 쿨 |
| `gray.3` (Divider) | `#dee2e6` | 쿨 |
| `--mantine-color-placeholder` | `#adb5bd` | 쿨 |
| body | `#f0eee6` | 웜 |
| accent | `#C96442` | 웜 |

`c="dimmed"`, 모든 보더, 모든 Divider, 모든 placeholder가 여기서 나온다. 웜 배경 +
쿨 뉴트럴은 "뭔가 어색함"의 가장 흔한 원인이다.

### (b) 카드 레이어링이 존재하지 않음 — 양쪽 스킴 모두

`app/globals.css`의 주석은 "카드(Paper)는 theme.white(#FAF9F5)로 한 단계 밝게"라고
주장하지만 **사실이 아니다.** Mantine v7+ `Paper`는 배경을
`--mantine-color-body`에서 가져온다. 그 변수를 페이지 색(크림)으로 덮었기 때문에
카드가 페이지와 같은 색으로 끌려 내려갔다.

| 스킴 | 실측 body | 실측 card | 판정 |
| --- | --- | --- | --- |
| light | `rgb(240,238,230)` | `rgb(240,238,230)` | 동일 — 레이어 없음 |
| dark | `rgb(38,38,34)` | `rgb(38,38,34)` | 동일 — 레이어 없음 |

`theme.ts`의 "dark.7=배경, dark.6=카드" 주석도 같은 이유로 사실이 아니다.
`theme.white`와 `dark.6`은 Paper에 도달하지 않는다. 카드가 서피스가 아니라
윤곽선으로만 보인다.

### (c) `defaultRadius: "lg"` = 16px 전역

높이 20px인 Badge와 `size="xs"` 컨트롤에도 16px 라운드가 걸려 화면 전체가
알약처럼 보인다.

### (d) 상태색이 Mantine 기본 고채도

`green #d3f9d8` · `red #fa5252` · `blue #228be6` — 저채도 어스톤 액센트 하나
옆에 고채도 4색이 경쟁한다. 히스토리 한 줄에 초록 배지 + 테라코타 `zip` +
핫핑크 `삭제`가 함께 있다.

### (e) 구조 문제

- 타입 스케일이 평평하다: 대부분 11~13px, 제목만 22~28px.
- 섹션 헤더가 4종류: 12px dimmed 라벨(`진행 로그`), 세리프 헤딩(`산출물`),
  Accordion(`픽셀 검증 리포트`), 카드 안 볼드 타이틀(`발송 준비`).
  `부분 수정`은 카드 없이 맨몸으로 카드 두 개 사이에 있다.
- 1512px 화면에서 680px 단일 컬럼 — 히스토리 표가 좁아 열이 줄마다 흔들린다.
- 아이콘이 이모지(`🔌 ⚙️ 🔔 🔕 ✓`).

## 2. 토큰

모든 대비값은 `docs`가 아니라 실제 WCAG 상대휘도 공식으로 계산해 확정했다.

### 웜 그레이 (`gray` 덮어쓰기 — 핵심 수정)

```
0 #F7F5F0   3 #CFCABB  divider      6 #6E6857  dimmed   9 #2E2A23
1 #EDEAE1   4 #B7B1A1  input border 7 #574F42
2 #E0DCD0   5 #948D7D  placeholder  8 #423C32
```

`dimmed #6E6857` — 페이지 위 **4.78**, 카드 위 **5.27** (기존 `#868e96`는 3.9로
AA 미달이었다). 이 하나로 dimmed·보더·Divider·placeholder가 동시에 웜으로 바뀐다.

### 레이어링 복구 (양쪽 스킴 동일 구조)

`--mantine-color-body`를 페이지 색으로 덮는 것을 **중단**하고, 그 변수를 카드 색으로
두고 페이지 배경은 `body` 엘리먼트에 직접 칠한다.

| 스킴 | page (`body`) | card (`--mantine-color-body`) | 대비 |
| --- | --- | --- | --- |
| light | `#F0EEE6` oat | `#FAF9F5` ivory | 1.10 |
| dark | `#1E1D19` | `#262622` | 1.11 |

부수 효과로 input·menu·popover도 카드 색을 따라가 일관된다.

### 상태색 → 저채도 어스톤

`theme.colors`에서 `green`/`red`/`blue`/`yellow`를 덮는다. 기존 `color="green"`
호출부는 그대로 두고 값만 바뀌므로 호출부 수정이 없다.

| 상태 | 배지 텍스트 / 배경 | 대비 | 카드 위 |
| --- | --- | --- | --- |
| 완료 sage | `#485832` on `#E0E7D4` | 6.09 | 4.56 |
| 실패 oxblood | `#73301F` on `#F1D9D3` | 7.19 | 7.02 |
| 실행 중 slate | `#444D62` on `#DCE0E9` | 6.39 | 6.07 |
| 경고 ochre | `#6A5119` on `#F3E5C4` | 6.00 | 4.43 |

실패색(oxblood)은 테라코타 액센트보다 의도적으로 더 깊게 둔다 — "실패"가 CTA로
읽히지 않게 하기 위해서다.

### 액센트

`primaryShade` 6 → **7** (`#BE5836`). 흰 라벨 대비 **4.53** 통과이고, 양쪽 스킴에서
같은 fill로 쓸 수 있다 (카드 대비 라이트 3.90 / 다크 3.35). 현재 primary 버튼이
비활성처럼 보이는 문제도 같이 해결된다.

앵커는 `--mantine-color-anchor`를 스킴별로 지정한다 — 라이트 `clay.8 #A64828`
(5.57), 다크 `clay.5 #CE8A64` (5.38). `clay.6`은 3.70으로 링크 텍스트에 부족하다.

### Radius / 타입

- radius 스케일 `xs:3 sm:5 md:8 lg:12 xl:18`, 기본 `md`. `Badge`·`Code`는 `sm` 고정.
- 타입 4단: `12` meta · `14` body · `17` 섹션 타이틀 · `24` 페이지 타이틀.
  세리프는 24/17에만, tracking `-0.01em`.

## 3. 구조

### 공유 컴포넌트 3개

- **`Section`** — 카드 + 17px 타이틀(좌) + 액션/상태 슬롯(우) + hairline.
  섹션 헤더 4종류 문제를 끝낸다. 두 화면의 모든 섹션이 이걸 쓴다
  (맨몸이던 `부분 수정` 포함).
- **`AppHeader`** — sticky full-bleed, hairline bottom. 페이지를 잡아주는 앵커가
  현재 전혀 없다.
- **`StatusDot`** — 점 + 라벨. 헤더·행·배지에서 같은 표현을 쓴다 (무지개 배지 제거).

- 컨테이너 680 → **920**. 본문 카피는 `~62ch`로 제한. 긴 Figma URL은 넓은 입력이
  오히려 유리하고, 히스토리 표는 정렬할 공간이 생긴다.
- 히스토리 행을 **실제 그리드**로: 크기/시간/액션 열 고정 폭 + `tabular-nums`.
  줄마다 열이 흔들리는 문제를 없앤다.
- **진행 로그 터미널이 작업 상세의 시그니처.** 웜 다크 서피스를 유지하되 hairline
  타이틀 바(현재 단계 + 자동 스크롤 토글)를 얹는다. 화면에서 유일하게 큰 소리를
  내는 요소로 두고 나머지는 조용하게 간다.
- 이모지 → **인라인 SVG 6개** (`app/components/icons.tsx`). 새 의존성 없음 —
  `@tabler/icons-react`가 설치되어 있지 않고, 글리프 6개는 의존성을 정당화하지
  못한다.

## 4. 범위 밖

아이덴티티(크림/테라코타/세리프), 모든 카피, 컴포넌트 경계, 모든 동작은 유지.
라우팅·상태·API 변경 없음. 토큰 + 공유 컴포넌트 3개 + 마크업뿐이다.

`data-testid`는 전부 보존한다 — 테스트 파일이 참조하진 않지만 AGENTS.md가 mock
프로바이더 브라우저 E2E에서 쓴다고 기록하고 있다.

`AGENTS.md`의 "components never branch on theme" 규칙은 유지된다 — 모든 수정이
토큰이거나 스킴 스코프 CSS 변수다.

사실과 달랐던 `theme.ts` / `globals.css` 주석은 방치하지 않고 바로잡는다.
