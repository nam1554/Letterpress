Letterpress 시작 안내서

Figma eDM 디자인 → 이메일 HTML. 처음 준비에 약 10분, 그 뒤로는 링크만 붙여넣으면 됩니다.

1앱 파일 압축 풀기

노션 페이지에 첨부된 Letterpress.zip을 내려받아 압축을 풉니다. 바탕화면이나 문서 폴더처럼 본인이 찾기 쉬운 곳에 두세요 — 앞으로 계속 여기서 실행합니다.

Windows라면 압축을 풀기 전에 zip 파일을 우클릭 → 속성 → 아래쪽 "차단 해제" 체크 → 확인을 먼저 해 주세요. 이걸 안 하면 실행 파일이 조용히 차단됩니다.

2본인 구독 하나 고르기

세 가지 중 이미 갖고 계신 것 하나만 준비하면 됩니다. 셋 다 실제 작업을 끝까지 돌려 같은 품질 기준을 통과한 기록이 있어서, 어느 쪽을 고르든 결과물 수준은 같습니다.

3실행하기

압축 푼 폴더 안의 시작하기.command를 더블클릭하세요. 검은 창이 뜨고 준비가 끝나면 브라우저가 자동으로 열립니다.

"확인되지 않은 개발자" 경고가 뜬다면 — 처음 한 번만 파일을 우클릭 → 열기로 실행하세요. 그 다음부터는 더블클릭으로 됩니다.

뜬 검은 창을 닫으면 앱이 종료됩니다. 쓰는 동안은 켜 두세요.

압축 푼 폴더 안의 시작하기.bat을 더블클릭하세요. 준비가 끝나면 브라우저가 자동으로 열립니다.

파이썬 설치 화면이 나오면 "Add python.exe to PATH"를 반드시 체크하세요. 체크하지 않으면 픽셀 검증이 실행되지 않습니다.

Windows는 아직 실기기 검증 전입니다. 막히는 지점이 있으면 화면 메시지와 폴더에 생기는 시작-기록.log를 함께 알려주세요.

Node.js·pnpm 설치, 앱 빌드, 포트 정리, Chrome 확인은 실행 파일이 알아서 처리합니다. 빠진 게 있으면 화면에 설치 방법을 안내합니다.

4앱 안에서 연동 마무리

브라우저가 열리면 화면에 🔌 백엔드 연동 패널이 있습니다. 2단계에서 고른 구독의 카드를 펼치면 설치 → 로그인 → Figma 접근이 단계별로 점검돼 있습니다.

  • 빨간/노란 단계에는 해결 방법과 복사 버튼이 함께 표시됩니다
  • 다 초록이 되면 "연동 테스트"를 한 번 눌러 보세요 — 실제 CLI를 아주 작은 프롬프트로 돌려 몇 초 만에 "진짜 동작함"을 확인합니다

10분짜리 변환을 돌려 보고 나서 실패를 알게 될 필요가 없습니다.

5첫 변환 돌려 보기

원인을 직접 찾을 필요 없습니다. 앱 화면의 "문제 신고용 파일 내려받기"(작업 히스토리 제목 오른쪽)를 누르면 압축 파일 하나가 내려받아집니다. 그걸 그대로 담당자에게 보내 주세요.
